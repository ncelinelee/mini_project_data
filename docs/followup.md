# 후속 실험 — 상대 용량과 검증 전략

## 질문

기존 Batch2 오차 분석에서 입력·수명 분포 차이를 확인했다. 초기 용량으로 상대화한 피처가 개발 데이터에서 더 안정적인지, 충전 정책을 분리하는 검증과 무작위 셀 분리의 점수가 어떻게 다른지 확인한다.

## 사전에 정한 비교

- 개발 대상: 기존 `holdout.json`의 Batch1 개발 35셀만 사용
- 평가 배제: Batch1 hold-out 11셀과 Batch2·3은 파라미터 선택·점수 계산에서 제외
- 외부 분리: 정책별 5-fold GroupKFold
- 내부 분리: 외부 학습 행에서만 정책별 3-fold GroupKFold
- 후보: ElasticNet · ln수명, alpha 0.001/0.01/0.1 × l1_ratio 0.2/0.5/0.8
- 기존 피처: ΔQ log분산, 초기 용량 중앙값, Qd100−Qd10, 평균 온도
- 상대 피처: log10 Var(ΔQ/Qearly), (Qd100−Qd10)/Qearly, 평균 온도
- 기준선: 산술 평균 예측. 이전 실험에서 고른 고정 모델도 참고용으로 함께 기록

표준화는 각 학습 폴드에서만 맞춘다. 모든 후보·폴드·외부 예측과 사용 환경을 CSV·manifest로 남긴다. 기존 `day2/results/`의 최종 모델과 성능 표는 덮어쓰지 않는다.

## 결과

| 방법 | 외부 폴드 평균 MAPE (%) | 폴드 표준편차 (pp) |
| --- | ---: | ---: |
| 평균 기준선 | 19.01 | 9.19 |
| 이전에 선정한 고정 설정 — 참고용 | 6.23 | 1.89 |
| 기존 피처 + nested 튜닝 | 6.27 | 1.79 |
| 상대 용량 피처 + nested 튜닝 | 7.80 | 2.31 |

상대 피처는 기존 피처보다 평균 MAPE가 약 1.53pp 높았다. 이 정의에서는 용량 수준을 제거하는 효과가 이득으로 이어지지 않았다. 표본이 작고 폴드도 서로 학습 데이터를 공유하므로, 이 차이를 통계적 유의성이나 미래 배치에서의 우열로 해석하지 않는다.

고정 모델의 정책 분리 CV는 6.23%, 무작위 셀 분리 CV는 6.71%였다. 무작위 분리에는 매 폴드 6~7개 정책 중복이 있었다. 이번 표본에서는 무작위 분리가 더 낮은 점수를 만들지 않았지만, 새로운 충전 정책을 예측하려는 목적에는 정책 분리가 더 맞다. 이 비교는 모델을 다시 선택하는 기준으로 쓰지 않았다.

## 해석의 경계

기존 고정 설정은 같은 개발 데이터에서 이미 골랐으므로 그 점수를 독립적인 기준 성능으로 볼 수 없다. nested 튜닝은 폴드 안에서 파라미터를 선택하지만, 상대 피처 가설 자체가 이미 관찰한 Batch2 오류에서 출발했다. 따라서 이 실험 전체도 새 외부 테스트를 대체하지 못한다.

새 배치의 성능 개선을 주장하려면 관찰하지 않은 데이터를 확보하고, 피처·선정 규칙을 먼저 고정한 뒤 평가해야 한다. 상대화는 이번 결과에서 채택하지 않았다. 실패한 가설과 검증 범위를 남기는 것을 후속 실험의 결과로 삼는다.

## 재현

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m day2.followup
```

원본 `.mat` 없이 커밋된 초기 피처 CSV로 실행 가능하다. [요약](../day2/followup_results/summary.csv), [폴드 점수](../day2/followup_results/fold_scores.csv), [OOF 예측](../day2/followup_results/predictions.csv), [분리 전략](../day2/followup_results/split_strategies.csv), [manifest](../day2/followup_results/manifest.json)를 함께 확인할 수 있다. 외부 평가셋의 목표값을 바꿔도 후속 실험 결과가 변하지 않는 테스트를 포함한다.
