학습 데이터는 Batch1이며 35셀 개발/11셀 hold-out으로 고정한다. 개발 35셀의 정책별 5-fold에서만 후보를 선정하고, 선정한 같은 모델로 Batch2 39셀과 Batch3 44셀을 평가한다. Batch2·3 점수로 피처·파라미터를 재선정하지 않는다. 최적 모델은 탐색한 후보 중 최저 CV 평균을 얻은 ElasticNet·D1·ln수명(alpha=0.01, l1_ratio=0.5)이다.

제출 표의 Train은 과제 정의에 따라 **Batch1 CV 평균 6.230%**다. DAY1 PDF의 기존 평가 계획에서는 학습 셀 재예측을 Train으로 불렀으나, 이번 DAY2 제출에서는 이 값(5.858%)을 `Fit_Batch1` 보조 지표로 명명했다. 분석 방법과 예측값은 동일하며 제출 표의 용어를 최신 과제 정의에 맞췄다.

Gap 행 이름은 과제 양식을 유지한다. 계산은 Valid−Train(CV), Test(Batch2)−Valid, 해당 Test−9.1%, Batch2−Batch3이며 모든 차이는 pp다. Batch2−Batch3=+28.161pp는 Batch2 오차가 더 크다는 뜻이다.

## 확인된 한계

- 제공된 원본에서는 Batch1·2의 수명 분포도 다르다. 안내의 일반적인 설명을 그대로 결론으로 쓰지 않고 실제 관측값을 보고했다.
- 같은 셀의 ΔQ 차분과 공통 전압 격자를 사용하지만 배치별 물리적 곡선 시작점 보정을 검증하지 않았다.
- 수명 결측은 제외하고 빈 기록은 결측 처리했다. 스파이크·장수명 셀은 오류 근거가 없어 보존했다. 원논문의 연속 실험 연결·품질 제외를 동일하게 재현한 결과는 아니다.
- EDA에서 평가 대상의 수명을 확인했고, 다수 후보 중 CV 최저점을 선택했다. 완전히 미관측한 테스트나 편향 없는 최적 성능이라고 주장하지 않는다.
- 회귀를 선택했으므로 MAPE를 보고한다. 분류의 F1/Accuracy는 이번 제출 태스크에 해당하지 않는다.
